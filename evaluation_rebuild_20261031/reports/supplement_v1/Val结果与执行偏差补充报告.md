## 4. C/D 对照与收益归因

C−B 的平均 AP50 差为 2.28 个百分点，D−B 为 1.29 个百分点，C−D 为 0.99 个百分点。
D 也优于 B，表明额外训练与微调学习率等过程本身可能带来收益；不能把 C 相对 B 的全部提升归因于温和增强。C/D 从各自同种子的完全相同 B 检查点开始，优化器、最大轮次和早停规则相同。
C/D 改变的是 HSV、scale、translate 组成的增强配方，不能将收益归因于其中一个单独增强项。早停使实际训练轮数不同，因此这里是相同最大预算与停止规则下的配方比较，不是严格相同更新步数的消融。

## 6. 本轮实际速度、导出与一致性

仅使用本轮 Val 360 张图；batch=1、输入 640、FP32。每个方案先进行一次不计时调用预热，再测量全部图片，中位数和 p95 均按单图延迟统计。只有一次预热，未做跨时段重复测速，热状态和功耗策略可能影响数值。
GPU 为训练日志中的 NVIDIA GeForce RTX 3060 Laptop GPU；GPU 测速显式同步 CUDA。PyTorch CPU 线程数为 2；ONNX Runtime 使用 CPUExecutionProvider，intra_op_num_threads=2，其他线程参数保留该框架默认值。原测速文件未记录 CPU 型号与历史温度，不补造这些信息。
计时覆盖 capture 中的读图/预处理、模型推理、融合及后处理，不含模型加载、预热、绘图、序列化和网络，不能直接承诺流水线端到端吞吐。GPU 实际一致性核对和 ONNX 均使用预先固定的 seed42，并非从三个种子中挑最高者。

- gpu_runtime / research：中位数 76.74 ms，p95 83.47 ms；相对对应 PyTorch/缓存参考的 AP50 差 +0.0040 个百分点，AP50:95 差 +0.0009 个百分点。
- gpu_runtime / balanced：中位数 76.31 ms，p95 84.00 ms；相对对应 PyTorch/缓存参考的 AP50 差 +0.0015 个百分点，AP50:95 差 +0.0013 个百分点。
- gpu_runtime / recall：中位数 75.80 ms，p95 83.65 ms；相对对应 PyTorch/缓存参考的 AP50 差 +0.0027 个百分点，AP50:95 差 +0.0021 个百分点。
- onnx / best_single：中位数 119.26 ms，p95 124.59 ms；相对对应 PyTorch/缓存参考的 AP50 差 -0.0073 个百分点，AP50:95 差 +0.0026 个百分点。
- onnx / balanced_no_tta_variant：中位数 234.32 ms，p95 241.72 ms；相对对应 PyTorch/缓存参考的 AP50 差 -0.0015 个百分点，AP50:95 差 -0.0341 个百分点。

ONNX 不执行 TTA。balanced_no_tta_variant 是无 TTA 分支，不能把它的速度与 GPU TTA 的精度拼成同一方案的宣传指标。上一轮 37 ms／105 ms 属于历史实验，不作为本轮测速结果。
