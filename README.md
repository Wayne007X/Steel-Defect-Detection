# 基于 YOLOv8 的钢材表面缺陷检测系统

## 📖 项目简介
针对热轧带钢表面缺陷人工质检效率低、漏检率高的问题，本项目基于 NEU-DET 公开数据集，使用 YOLOv8n 训练了一套工业视觉缺陷检测模型，并**已基于 Streamlit 完成工程化 Web 部署闭环**。

## 🎯 核心成果
- **检测类别**：6类工业缺陷（裂纹、夹杂、斑块、点蚀、麻面、划痕）
- **数据集**：NEU-DET 钢材表面缺陷数据集（1800张图像，按 8:2 划分训练/验证集）
- **技术栈**：Python 3.10 + PyTorch 2.5 + YOLOv8 + OpenCV + Streamlit

## 📊 模型性能（在验证集上的表现）

## 💡 核心难点分析与工程优化
- **难点分析**：模型对斑块（mAP 0.937）和划痕（mAP 0.842）检测效果极佳，但对裂纹（mAP 0.458）检出率较低。分析原因为裂纹对比度极低、形状细长，与正常钢材纹理高度相似。后续计划通过引入注意力机制（Attention）和增加难例数据增强（如对比度拉伸）来提升该类别的召回率（Recall）。
- **数据清洗**：将原始的 VOC XML 标注格式，通过 Python 脚本批量转换为 YOLO 标准的归一化 txt 格式。
- **零污染训练**：针对工业低对比度缺陷，保留数据集中图片的子文件夹结构（按类别），实现了零数据污染的训练。
- **工程化部署**：利用 Streamlit 极速构建前端，实现了用户上传图片到模型推理的完整闭环，并加入侧边栏参数控制功能。
